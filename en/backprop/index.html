Forward and backward passes

A small neural network, advanced one node at a time. The forward pass that carries values onward, the backward pass that carries slopes back, and the weight update all happen on the same screen. Every gradient the backward pass produces can be set beside the answer you get by nudging that one weight and running the forward pass again.

Central question
How can we tell which weight to move, and in which direction, to make the error smaller?
Assumed background
You have met differentiating a composed function (the chain rule). You can read the slope of a graph. You have met the idea of repeating the same operation.
Written for
University and adult learners

A step is one node. A pass runs from the forward pass to the weight update.

Circles are nodes and lines are weights. The node of the current step is outlined, with a mark above it (▶ forward, ◀ backward, ∂ gradient, ± cross-check, ↻ update). Weight values appear only on the lines involved in that step. The number inside a circle is that node's output; δ below a circle is the value from the backward pass. What you can do here

  • Set side by side the gradient from the chain rule and the one you get by nudging that weight and running the forward pass again. Both losses, at ±0.001, are shown.
  • Step through one node at a time to follow which value came from which expression. You can step back as well.
  • Change the number of layers and nodes, the inputs, the targets, the learning rate and the initial weights (the seed), and compare how the loss comes down.

Start at the output node. There δ is simply "output − target".

For a hidden node, δ is the δ of the next layer times the weights, added up, then multiplied by the slope of the activation. The next layer has to be done first.

The gradient of a weight is "the value it carries" × "the δ of the node it feeds". So once δ is known, every weight into that node is settled at the same time.

In more detail
Wording

Measure how far off the answer is at the exit, then hand that miss back along the paths it came by. Once it has been handed all the way back, you know which way and how far to move every weight. Unlike nudging and testing, nothing has to be run again.

With L = ½Σ(y − t)², the output layer has δ = ∂L/∂z = y − t. A hidden layer has δj = f′(zj) Σk wkj δk. For the weights, ∂L/∂wji = ai δj, and for the biases ∂L/∂bj = δj. The update is w ← w − η ∂L/∂w.

For teachers

A common misreading: that backpropagation works by changing weights a little and seeing what happens. The numerical differentiation here is done for one weight only, as a check. With twenty weights, testing would mean forty more forward passes; backpropagation settles all of them in a single backward sweep.

Short tasks (5–10 minutes each). Every one has the same shape: change something, watch, then put it into words.

  • Compare learning rates. Compare 0.1 and 1.5 and watch how the loss comes down. Find a setting where it stops coming down, or bounces, and put into words why that happens.
  • Set an input to zero. Set input 1 to 0, run one pass and look at the table of weights. Every gradient on a weight leaving input 1 is exactly 0. Explain why, from “∂L/∂w = output of the previous layer × δ”.
  • Find a node that stops. Set the hidden activation to ReLU and the seed to 4, then run one pass. Some nodes end up with δ = 0; confirm in the table that the weights into them do not move, then switch back to sigmoid and compare.
  • Count the re-runs. Set 4 inputs, hidden layers of 5 and 5, and 3 outputs, then count the weights (60). Work out how many forward passes the “nudge and test” method would need, and how many the backward pass needs.
  • Try three seeds. Keeping the shape and the values, set the seed to 1, 3 and 7 and write down the loss at pass 1 and at pass 6. Say how the starting weights change the run, and what stays the same anyway.
  • Remove the hidden layer. With no hidden layer the loss still comes all the way down. Tie that to the fact that this screen has a single training example, and put into words what can and cannot be checked here.

What this screen covers

  • This is not a working trainer. There is a single training example, and the network is limited to 3 hidden layers of up to 5 nodes. It cannot be used to compare speed either.
  • The output layer is the identity and the loss is squared error only. Softmax and cross-entropy, used for classification, are not included.
  • The step for numerical differentiation is fixed at 0.001. A different step gives a slightly different value, so the two numbers need not agree to every digit shown.
  • The arithmetic is floating point, and values are rounded to six decimals for display.
  • The only optimiser is plain gradient descent. Momentum, Adam, regularisation and mini-batches are not included.
  • No check of learning effect has been carried out. What is published here is a draft of the material.
