k-means

Splitting a set of points into groups, one step at a time: assigning each point to a centroid, then moving each centroid. Work through it while watching what each step actually changed.

The question
What follows from choosing the number of clusters, k, yourself?
Assumed background
Coordinates and averages. Written for upper-secondary level and above.
Predict before you run it
Data holds three blobs and you set k to 5. Where do you expect the five centroids to settle?

Each cluster has its own colour and marker shape; centroids are larger numbered markers. If colours are hard to tell apart, the shape and the number still identify the cluster.

    Things to check

    • Compare: keep three blobs in the data and try k as 2, then 3, then 5. Compare where the centroids settle.
    • Explain: pressing "Next step" alternates between a step that recolours points and a step that moves centroids. Say in your own words what each of the two decided.
    • Transfer: change the seed and run the same k again. Is the result the same? If it differs, what caused that?

    Limits of this procedure

    • Distance is Euclidean. Mixing axes with different units distorts the result.
    • Roughly round blobs are assumed. Elongated or unevenly dense distributions do not suit it.
    • The result depends on the initial centroids, which is why the seed is adjustable here.
    • k is chosen by a person; it does not follow from the data.
    • Outliers pull centroids towards them.
    • When a cluster ends up with no points, its centroid is moved to the farthest point. That is one implementation choice among several, not the single correct answer.

    Known gaps

    • No check of learning effect has been carried out. This page is a draft of the material.
    • Testing on target devices is outstanding.
