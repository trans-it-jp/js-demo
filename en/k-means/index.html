k-means

Splitting a set of points into groups, one step at a time: assigning each point to a centroid, then moving each centroid. Work through it while watching what each step actually changed.

The question
What follows from choosing the number of clusters, k, yourself?
Assumed background
Coordinates and averages. Written for upper-secondary level and above.
Predict before you run it
The points are scattered uniformly, with no groups in them. With k set to 3, where do you expect the dividing lines to fall?

Each cluster has its own colour and marker shape; centroids are larger numbered markers. If colours are hard to tell apart, the shape and the number still identify the cluster.

Predict before you run it

The points are scattered uniformly, with no groups in them. With k set to 3, where do you expect the dividing lines to fall?

You can operate the demo without choosing. Choosing lets you compare against the result afterwards.

    Things to check

    • Compare: try k as 2, then 3, then 5, and compare how the field gets divided. Every k produces boundaries that look plausible.
    • Explain: pressing "Next step" alternates between a step that recolours points and a step that moves centroids. Say in your own words what each of the two decided.
    • Transfer: press "Reset" for a different layout and run the same k again. Does it settle the same way? If it differs, what caused that?

    Look at where the initial centroids were placed.

    The points are equally dense everywhere, so a boundary falls where two centroids are equally far away.

    The boundaries follow only from the centroid positions. Different starting centroids give a different division.

    In more detail
    Wording

    Each point joins whichever centre is nearest. Once the groups are settled, each centre moves to the middle of its own group. Then it all repeats.

    Assign each point x to its nearest centroid c, then move each centroid to the mean of its cluster. The sum of squared distances Σ‖x − c‖² decreases on every iteration and the procedure stops once no assignment changes.

    For teachers

    A common misreading: treating the boundaries as evidence that groups were found in the data. The points here are uniform, so there is no correct division to find.

    A short task (5–10 minutes): compare k at 2, 3 and 5, then discuss whether one of them can be called correct. Realising that none can is the point.

    Limits of this procedure

    • It splits the data into k parts whether or not any grouping is there. The points in this demo are scattered uniformly, so there is no "correct" division to find. Boundaries appearing is not evidence that groups were found.
    • Distance is Euclidean. Mixing axes with different units distorts the result.
    • Where grouping does exist, roughly round blobs are assumed. Elongated or unevenly dense distributions do not suit it.
    • The result depends on the initial centroids. "Reset" gives a different layout to compare against.
    • k is chosen by a person; it does not follow from the data.
    • Outliers pull centroids towards them.
    • When a cluster ends up with no points, its centroid is moved to the farthest point. That is one implementation choice among several, not the single correct answer.
