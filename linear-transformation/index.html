2D 座標変換

図形を動かす操作が、行と列のある数表の掛け算として書けることを確かめます。平行移動を同じ形で書くために 3×3 の同次座標を使い、5 つのレッスンで一次変換から任意点中心の回転まで順に進みます。

前提
座標と、行列の掛け算。高校以降・大学を想定しています。
共通の約束
点は列ベクトル v = [x, y, 1]^T。行列は左から掛けます。
合成の順序
M = A·B を点に適用すると A(Bv)。右の行列が先に効きます。

レッスン

  1. 一次変換

    拡大縮小・せん断・反転を 1 つの行列にまとめる。行列の列が基底ベクトルの像であることを見る。

  2. 平行移動

    2×2 では書けない操作。3 列目に移動量を置く理由を、行列の 3 行目と合わせて確かめる。

  3. 一次変換と平行移動の合成

    順序が結果を変えること。T·L として組むと点には L が先に効く。

  4. 原点中心の回転

    長さと角度が変わらないこと。行列式がつねに 1 であることを数値で見る。

  5. 任意の点を中心にした回転

    T(c)·R(θ)·T(−c) の 3 つの積。原点へ運び、回し、戻す流れを分けて見る。

この教材の範囲

  • 扱うのはアフィン変換までです。行列の 3 行目は常に [0, 0, 1] で、射影変換は含みません。
  • 各レッスンの図では、描いた線・円・四角形・自由曲線も同じ行列で変換されます。
  • 図形の描画はポインタ操作だけで、キーボードからは行えません。パラメータはすべてスライダーと数値入力の両方で変えられます。
  • 学習効果の確認は行っていません。この教材は題材の試作です。

詳しい解説

行列の定義、逆行列、任意点中心の回転の一般式、例題は 解説（Readme.md） にあります。
