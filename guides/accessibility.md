# アクセシビリティ確認票

[English](accessibility.en.md)

公開前に 1 題ずつ確認する。**この票が埋まっていることは WCAG 適合の証明ではない。** 自動で測れるものと、人が実機で確かめるしかないものを分けてある。

参照: [WCAG 2.2 クイックリファレンス](https://www.w3.org/WAI/WCAG22/quickref/)

## 1. 自動で測れるもの

```bash
node tools/check-contrast.js   # 色のコントラスト比
node tools/check-links.js      # リンクと日英の対応
node tests/run.js              # 計算の既知値・境界値
```

| 項目 | 基準 | 確認方法 | 状態 |
| --- | --- | --- | --- |
| 文字のコントラスト比 | 4.5:1 以上 | `check-contrast.js` | 2026-10-25 全 23 組が通過 |
| 操作部品・図の要素のコントラスト比 | 3:1 以上 | 同上 | 同上 |
| 系列色どうしの近さ | 近い組み合わせを把握し、形と番号で補う | 同上の後半 | 把握済み。形 7 種と番号で補っている |

コントラスト比は色の値だけから計算している。実際の画面では重なり・不透明度・端末の表示で変わるため、これだけで合格にしない。

## 2. 設計で守っているもの（実装時に確認）

| 項目 | 守りかた | 確認するところ |
| --- | --- | --- |
| 色だけに頼らない | 色・形・番号・破線・数値を併用 | 散布図のクラスタ、図形の元と変換後 |
| ドラッグ以外の手段 | すべての数値にスライダーと数値入力の両方 | 各デモの「条件を変える」 |
| 図の代替 | 同じ数値を表でも出す | クラスタの内訳表、行列の表 |
| 状態の通知 | `aria-live="polite"` の領域へ現在の段階を書く | k-means の `#live` |
| 図の説明 | SVG に `role="img"` と `aria-label` | `js/viz/plane.js`・`scatter.js` |
| 本文への移動 | 先頭に skip link | 全ページ |
| 焦点の可視化 | `:focus-visible` で輪郭を出す | `css/site.css` |
| 動きを減らす設定 | `prefers-reduced-motion` を尊重 | `css/site.css` |
| 小画面・拡大 | 図は `viewBox`、横あふれを出さない | 幅 375px で確認 |

## 3. 人が確かめるもの（未了）

ここは機材と人が要る。**済んだことにしない。**

| 項目 | 確認方法 | 状態 |
| --- | --- | --- |
| キーボードだけで操作できるか | Tab・Shift+Tab・Enter・Space・矢印だけで全操作 | 未確認 |
| 焦点の順序が画面の並びと合うか | 同上 | 未確認 |
| 画面読み上げで内容が伝わるか | NVDA / VoiceOver / ナレーター | 未確認 |
| 実機の表示 | 対象のタブレット・スマートフォン・学校端末 | 未確認（エミュレーションのみ） |
| 拡大表示 | ブラウザ 200% と OS の文字拡大 | 未確認 |
| 投影 | 実際の教室の投影機で線と文字が判別できるか | 未確認 |
| 色覚差のある人の見え方 | 本人の確認、またはシミュレーション | 未確認 |
| 校内の通信制約 | 外部 CDN（D3）が届くか | 未確認 |

## 4. 今の未対応

| 内容 | 影響 | 扱い |
| --- | --- | --- |
| 図形の描画がポインタ操作だけ | キーボードだけでは線・円・四角形・自由曲線を描けない | 各ページに明記。数値パラメータはすべて数値入力で操作できる |
| 一時停止の操作が無い | 自動で動き続ける表示が現時点で無いため未実装 | 連続動作を持つ題材を足すときに実装する |

## 5. 記録

確認した結果は `planning/OPERATIONS.md`（管理リポジトリ）の「端末と操作の確認」へ、日付・端末・条件・結果・未確認を分けて書く。エミュレーションと実機を区別する。
