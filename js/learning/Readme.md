# js/learning — 学習の手順

[English](Readme.en.md)

小さなニューラルネットの順伝播・逆伝播・重みの更新を「手順」として出す。描画も DOM も扱わないので、Node からそのまま照合できる。

| ファイル | 役割 |
| --- | --- |
| `net.js` | 順伝播・逆伝播・数値微分・更新の手順（`JsDemo.Net`） |

## 読み込み方

`JsDemo.Random` と `JsDemo.Numeric` を使う。

```html
<script src="../js/core/seeded-random.js"></script>
<script src="../js/core/numeric.js"></script>
<script src="../js/learning/net.js"></script>
```

## 決めごと

- **1 手はノード 1 つ分。** どのノードの、どの値が、どの式で決まったかを 1 手で言える粒度にする。層ごとにまとめると「どこから来た値か」が追えなくなる。
- **逆伝播は連鎖律で解く。** 数値微分（少し動かして順伝播をやり直す）は答え合わせとして別に出す。**逆伝播そのものを試行錯誤に見せない。**
- 中間層の活性化は sigmoid か ReLU、**出力層は恒等**、損失は二乗誤差（係数 1/2）。1/2 は `∂L/∂y = y − t` を余計な 2 無しで書けるようにするため。
- **損失は丸めない。** 数値微分は損失の差を刻み幅で割るので、ここで丸めるとその誤差が 1000 倍に拡大して「一致しない」ように見える。表示用の丸めは手順を作るときに行う。
- 初期の重みは**種から決める**。同じ種なら何度でも同じ実験になる。手で検算できるよう小数 2 桁へ丸め、偏りは 0 から始める。
- **手順を先に全部は作らない。** 学習は何周でも続けられるので、終わりまでの手数は存在しない。`run()` は求められた分だけ周回を作る。

## 使い方

```js
var plan = JsDemo.Net.run({
  inputs: 2, outputs: 1, hidden: [3],
  input: [0.5, -0.2], target: [1],
  rate: 0.5, seed: 3, activation: "sigmoid"
});

plan.ensure(40, { probe: "max" });   // 40 手になるまで周回を作る
var state = JsDemo.Net.replay(plan.initial, plan.steps, 10);  // 10 手進めた状態
```

`probe` は答え合わせする重み。`"max"` なら勾配がいちばん大きい重み、`{layer, node, from}` なら名指し、`null` なら答え合わせをしない。

## 手順の種類

| type | 中身 |
| --- | --- |
| `forward` | そのノードの `z`（重み×前の層の出力の合計）と `a`（活性化を通した値） |
| `loss` | 出力ごとの `y`・教師値・差と、損失 |
| `delta` | そのノードの δ。出力層は `y − t`、中間層は次の層の δ と重みから |
| `grad` | その δ から決まる、ノードへ入る重みの傾きと偏りの傾き |
| `probe` | 重みを ±h 動かしてやり直した順伝播の損失、数値微分、逆伝播の値、その差 |
| `update` | その層の重みと偏りを `w − 学習率 × 傾き` へ書き換える |
| `epochEnd` | 1 周の終わり。その周の損失 |

`applyStep(state, step)` は state を変えずに新しい state を返す。巻き戻しは最初から畳み直す。

## 確かめていること

`tests/cases.js` の「順伝播・逆伝播」で照合している。

- **逆伝播の傾きと数値微分が一致する**（中心差分、許容差 1e-4）。形と活性化を変えても成り立つ
- 手で解ける小さな形（入力1・中間層なし・出力1）の値が手計算と一致する
- 1 手ずつ畳んだ結果と、まとめて畳んだ結果が一致する
- 同じ種なら初期の重みが同じになる
- 学習を続けると損失が下がる（単調とは限らないので、始めと終わりで比べる）
