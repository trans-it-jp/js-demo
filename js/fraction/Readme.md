# js/fraction — 分数を同じ全体で比べる

[English](Readme.en.md)

2 つの分数を「同じ全体」で比べる手順を作る。描画も DOM も扱わないので、Node からそのまま照合できる。

| ファイル | 役割 |
| --- | --- |
| `compare.js` | 通分・比較・手順の生成（`JsDemo.Fraction`） |

## 読み込み方

`JsDemo.Numeric` を使う。

```html
<script src="../js/core/numeric.js"></script>
<script src="../js/fraction/compare.js"></script>
```

## 決めごと

- **扱うのは 0 以上 1 以下の分数だけ。** 分子は分母を超えない。仮分数・帯分数・負の分数、加減乗除、約分の練習は初期に含めない（学習設計 3 章）。
- **そろえ直す手を必ず通す。** 手順は「分ける → 塗る → 分ける → 塗る → そろえ直す → 数える」の 6 手で、同じ分け方にそろえずに比べる道筋を作らない。
- **基準の全体は変えない。** 画面の 2 つの正方形はいつも同じ大きさで、違う全体どうしを比べる操作は用意しない。
- **既約化はしない。** 見せたいのは「分け方をそろえると数えられる」ことで、約分の手続きではない。1/2 と 2/4 は**同じ面積**として出る。
- 分母の上限は 12。これより細かく分けると、面積の違いが目で分からない。
- **不正な入力は弾かずに範囲へ寄せる。** 分母 0 は 1、分子が分母より大きければ分母に合わせる、負の数や文字は 0 にする。URL も入力欄も、誰でも書き換えられるため。

## 使い方

```js
var a = JsDemo.Fraction.make(2, 3);
var b = JsDemo.Fraction.make(3, 5);

JsDemo.Fraction.compare(a, b);        //  1（左が大きい）
JsDemo.Fraction.common(a, b);         //  15 等分にそろえた形
JsDemo.Fraction.toPercent(a);         //  66.7

var steps = JsDemo.Fraction.steps(a, b);
var state = JsDemo.Fraction.replay(a, b, steps, 5);  // 5 手進めた状態
```

## 手順の種類

| type | 中身 |
| --- | --- |
| `divide` | その側の正方形を分母の数だけ分ける |
| `fill` | 分子の数だけ塗る |
| `recut` | 両方を分母の最小公倍数で分け直す。`already` が真なら、もとから同じ分け方 |
| `count` | そろえた分け方で数え、大小を決める |

`applyStep(state, step)` は state を変えずに新しい state を返す。巻き戻しは最初から畳み直す。

state の `base` は**最初に分けた数（もとの分母）**で、そろえ直しても変えない。もとの分け方を図に残し、「面積は動いていない」ことを線の太さで見せるために使う。

## 確かめていること

`tests/cases.js` の「分数」で照合している。

- **既知値**: 2/3 と 3/5 は 10/15 と 9/15、5/8 と 2/3 は 15/24 と 16/24
- **等しい分数**: 1/2 と 2/4、2/3 と 4/6 は `compare` が 0
- **不正入力**: 分母 0・分子が分母より大きい・負・文字・小数を入れても、範囲の中の分数になる
- **面積が動かない**: そろえ直しの前後で、塗った割合（分子 ÷ 分母）が変わらない
- 小数・百分率の丸め、最大公約数と最小公倍数の既知値
